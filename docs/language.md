# 이음 언어 안내

이음의 문법과 실행 규칙입니다. 내장 동사는 [내장 동사](stdlib.md)에 있습니다.

```ieum
점수들은 [72, 95, 88]이다.
합계는 0이다.
점수들 중 점수마다:
    합계를 (합계 + 점수)로 바꾼다.
합계가 250 이상이면:
    "우수 반"을 출력한다.
```

## 문장과 줄

문장은 마침표로 끝나고 한 줄에 하나씩 씁니다. 블록은 콜론으로 열고 공백 네 칸씩 들여씁니다. `#`부터 줄 끝까지는 주석입니다.

소스는 UTF-8이며 LF와 CRLF를 모두 읽습니다. 이름은 `합계`, `x_1`, `_임시`처럼 Unicode 식별자(XID) 규칙을 따르고 NFC로 정규화합니다.

리터럴과 같은 철자를 이름으로 쓰려면 `` `참` ``처럼 역따옴표로 감쌉니다. 역따옴표 안에도 공백은 쓸 수 없습니다(`` `두 단어` ``는 `E-NAME-001`).

### 조사

조사는 앞말에 붙여 쓰고 어절 사이는 띄웁니다. 조사를 붙일 대상이 복합 식이면 `(합계 + 5)로`처럼 괄호로 감쌉니다.

조사는 앞말의 받침에 맞는 모양을 씁니다: `책을`과 `사과를`, `부산으로`와 `서울로`. 숫자는 읽는 소리를 따르고(`3을`, `2를`, `10을`), 모음 글자가 없는 대문자 약어는 글자 이름으로 읽습니다(`CSV를`, `HTML로`). 맞지 않으면 `E-AFFIX-004`입니다.

소리를 알 수 없는 말 뒤에는 어느 모양이든 쓸 수 있습니다. `)`, 영어 낱말, `HOME`처럼 낱말로도 읽히는 대문자가 그렇습니다.

## 값

| 종류 | 예 | 비고 |
| --- | --- | --- |
| 정수 | `42`, `-7`, `0x1f`, `1_000` | 임의 정밀도 |
| 실수 | `3.14`, `1e-3` | binary64 |
| 문자열 | `"안녕\n"`, `'\d+'` | 큰따옴표: 이스케이프(`\n` `\r` `\t` `\"` `\'` `\\` `\uXXXX` `\UXXXXXXXX`)와 `{식}`. 작은따옴표: 쓴 그대로 |
| 논리 | `참`, `거짓` | |
| 없음 | `없음` | |
| 목록 | `[1, 2, 3]` | 가변 |
| 튜플 | `(1, "가")`, `(1,)`, `()` | 불변 |
| 집합 | `{1, 2}` | 빈 집합은 `([]를 집합변환한 값)` |
| 사전 | `{"이름": "하나", "점수": 80}` | 삽입 순서 유지. `{}`는 빈 사전 |

### 연산자

| 구분 | 연산자 |
| --- | --- |
| 산술 | `+ - * / // % **` |
| 비교 | `== != < <= > >=` |
| 논리 | `그리고`, `또는`, `아님` |

`/`는 항상 실수를 돌려줍니다. `//`와 `%`는 내림 나눗셈이라 `-3 // 2`는 `-2`입니다.

`**`는 정수끼리이고 지수가 0 이상이면 정확한 정수, 그 밖에는 `2 ** 0.5`처럼 실수입니다. 0의 음수 거듭제곱은 `E-RUNTIME-002`, 음수의 분수 거듭제곱은 `E-VALUE-001`, 실수 범위를 넘으면 `E-NUMERIC-001`입니다.

비교는 `1 < 수 < 10`처럼 이어 쓸 수 있습니다. 논리 연산은 논리값만 받고 단락 평가하며, `아님`은 `(합격 아님)`처럼 피연산자 뒤에 씁니다.

`+`의 어느 한쪽이 문자열이면 다른 쪽을 출력할 때의 모습으로 바꿔 잇습니다. `("합계: " + 10)`은 `합계: 10`, `(10 + "a")`는 `10a`입니다.

### 문자열 끼워 넣기

큰따옴표 문자열 안의 `{식}`은 그 값을 출력할 때의 모습으로 채웁니다.

```ieum
"{품목의 이름}: {품목의 수량}개"를 출력한다.
```

`{` 안에는 문자열을 포함해 어떤 식이든 쓸 수 있습니다: `"{(목록을 ", "로 연결한 값)}"`, `"{사전["키"]}"`. 중괄호 자체는 `{{`, `}}`로 씁니다. 닫히지 않은 `{`, 짝 없는 `}`, 빈 `{}`는 `E-STR-004`입니다.

작은따옴표 문자열은 이스케이프도 `{식}`도 없이 쓴 그대로이므로 정규식과 JSON에 씁니다: `'\d{3}-\d{4}'`, `'{"가": 1}'`. 작은따옴표 자체는 담을 수 없습니다.

### 서식

`{식:서식}`으로 모양을 정합니다. `{` 안의 첫 `:`부터가 서식이고, 문법은 `[[채움]정렬][부호][z][#][0][폭][,|_][.자릿수][형식]`입니다. 예: `"{금액:,}원"`, `"{비율:.1%}"`, `"{값:08.2f}"`, `"{번호:#x}"`, `"{-5:03}"`(`-05`).

정렬은 `<`(왼쪽), `>`(오른쪽), `^`(가운데), `=`(부호 뒤를 채움)이고, 정렬 앞의 글자로 빈칸을 채웁니다(`*>8`). 수는 오른쪽, 그 밖의 값은 왼쪽 정렬이 기본입니다. 폭은 터미널 칸 수로 세며 한글은 두 칸입니다: `"{이름:<8}{금액:>12,}원"`.

형식은 정수에 `d`, `b`, `o`, `x`, `X`, 실수에 `f`, `e`, `g`, `%`, 문자열에 `s`를 씁니다. 실수 형식은 정수에도 쓸 수 있지만 정수 형식은 실수에 쓸 수 없습니다. 형식 없이 `.자릿수`만 쓰면 어떤 수든 소수 그 자리까지 씁니다(`"{3:.2}"`는 `3.00`). 문자열에 쓴 `.자릿수`는 그 글자 수까지만 남깁니다.

시각에는 `"{날짜:%Y년 %m월 %d일}"`처럼 strftime 서식을 씁니다. 모르는 서식이나 값에 맞지 않는 서식은 `E-FORMAT-001`입니다.

### 여러 줄 문자열

따옴표 세 개로 씁니다. `"""`는 큰따옴표처럼 이스케이프와 `{식}`을 쓰고, `'''`는 쓴 그대로입니다.

```ieum
안내는 """
    안녕하세요, {이름}님.
    오늘의 할 일은 {할일들의 길이}개입니다.
    """이다.
```

여는 따옴표 바로 뒤의 줄바꿈과 닫는 따옴표 앞의 줄바꿈은 내용에 들어가지 않습니다. 모든 줄에서 닫는 따옴표의 들여쓰기만큼 걷어 내며, 그보다 덜 들여 쓴 줄은 `E-STR-005`입니다.

`"""안녕"""`처럼 한 줄에 써도 됩니다. CRLF로 저장한 파일에서도 줄바꿈은 `\n`입니다.

### 범위, 인덱스, 속성

`(1부터 10까지)`는 1부터 10까지의 정수 목록이고, `(10부터 1까지 내려가며)`는 거꾸로 셉니다. 예: `(1부터 100까지)의 합계`.

인덱스와 슬라이스는 목록, 튜플, 문자열에 쓰며 음수 인덱스와 간격도 받습니다. 예: `자료[0]`, `자료[-1]`, `자료[1:3]`, `글[::-1]`.

속성은 `의`로 읽습니다.

| 대상 | 속성 |
| --- | --- |
| 모든 컬렉션과 문자열 | `길이` |
| 목록, 튜플, 집합 | `합계`, `평균`, `최댓값`, `최솟값` |
| 수 | `절댓값`, `제곱근`, `사인`, `코사인`, `탄젠트`, `아크사인`, `아크코사인`, `아크탄젠트`(각은 라디안), `자연로그`, `상용로그`(밑 10), `이진로그`(밑 2) |
| 사전 | `키들`, `값들`, `항목들`, 문자열 키 |
| 경로 문자열 | `파일이름`, `확장자`, `상위폴더` |
| 오류 | `코드`, `메시지`, `원인` |

사전의 문자열 키도 속성처럼 읽어서 `학생의 이름`은 `학생["이름"]`과 같습니다. 다만 `길이`, `키들`, `값들`, `항목들`은 같은 이름의 키가 있어도 사전 자신의 속성이므로, 그런 키는 `사전["길이"]`처럼 읽습니다. 이 네 속성은 바꿀 수 없습니다.

## 정의와 변경

```ieum
합계는 0이다.
합계를 (합계 * 2)로 바꾼다.
합계를 5만큼 늘린다.
상수 세율은 0.1이다.
학생의 점수를 90으로 바꾼다.
```

`이다`로 끝나는 문장은 새 이름을 정의하고, `바꾼다`로 끝나는 문장은 이미 있는 이름이나 원소의 값을 바꿉니다. 수는 `늘린다`와 `줄인다`로도 바꿀 수 있으며(`합계를 5만큼 줄인다.`), 대상과 양이 수가 아니면 `E-TYPE-001`입니다.

받침 없는 말 뒤의 `이다`는 `다`로 줄여 쓸 수 있습니다: `이름은 "하나"다.` `이면`과 `이고`도 같습니다(`"준비"면`, `"가"고`). 받침 뒤에서는 `이다`만 씁니다.

이 때문에 `점수이다`는 `점수`+`이다`로도 `점수이`+`다`로도 읽힙니다. 정의된 이름 쪽으로 읽고, 둘 다 있으면 `E-RESOLVE-002`입니다. `철수의 나이다`처럼 필드 이름이 갈릴 때는 실행할 때 값이 가진 필드로 정합니다.

블록마다 범위가 생기고, 블록 안에서 정의한 이름은 그 블록 밖에서 보이지 않습니다. 한 범위에서 같은 이름을 두 번 정의할 수는 없습니다.

이름은 정의한 문장보다 앞에서 쓸 수 없습니다(`E-INIT-001`). 함수 본문은 부를 때 실행되므로, 본문 안에서는 뒤에 정의한 이름도 쓸 수 있습니다.

`상수`로 정의한 이름에는 다른 값을 넣을 수 없습니다. 고정되는 것은 이름이므로, 상수가 가리키는 목록의 원소는 바꿀 수 있습니다.

## 함수 정의

함수는 "-는 법"으로 정의합니다. 매개변수는 역따옴표로 감싼 이름에 역할 조사를 붙여 선언합니다.

```ieum
`앞`을 `뒤`(기본 2)와 더하는 법:
    (`앞` + `뒤`)를 반환한다.
```

### 역할과 인자

| 조사 | 역할 |
| --- | --- |
| 이/가 | 주체 |
| 을/를 | 대상 |
| 에게 | 받는 쪽 |
| 에 | 위치나 목적지 |
| 에서 | 출처 |
| 으로/로 | 방향이나 수단 |
| 와/과 | 상대 |
| 만큼 | 양 |

한 함수에서 같은 역할은 한 번만 씁니다. 호출할 때는 인자의 순서를 바꿔도 됩니다. `(3을 4와 더한 값)`과 `(4와 3을 더한 값)`은 같습니다.

`(기본 식)`은 생략할 수 있는 인자의 기본값입니다. 기본값은 정의 문장을 실행할 때 한 번 계산해 함수에 보관합니다. 그래서 `[]` 같은 가변 기본값은 모든 호출이 같은 값을 씁니다.

본문에서는 매개변수를 역따옴표 없이 써도 되지만, 관례는 `` `앞` ``처럼 역따옴표로 쓰는 것입니다.

### 그대로 쓰는 낱말

머리에서 역따옴표 없이 조사를 붙인 낱말 하나는 동사의 일부가 됩니다("명사+동사" 합성).

```ieum
할일을 불러오는 법:
    ("할일.json"을 읽어서 JSON해석한 값)을 반환한다.
`목록`에서 다음번호를 구하는 법:
    (`목록`의 길이 + 1)을 반환한다.

목록은 (할일을 불러온 값)이다.
(목록에서 다음번호를 구한 값)을 출력한다.
```

`` `목록`에서 다음번호를 구하는 법 ``은 동사 `다음번호구하다`를 정의합니다. 호출은 `(목록에서 다음번호를 구한 값)`으로도, `(목록에서 다음번호구한 값)`으로도 씁니다. 함수 값은 `(다음번호구하다)`입니다.

호출의 낱말은 정의와 같은 역할이어야 합니다(`다음번호를`). 이렇게 맞는 정의는 같은 동사의 다른 정의보다 우선합니다.

그대로 쓰는 낱말은 한 정의에 하나입니다. 본문에서 그 낱말을 이름으로 쓰면 역따옴표를 빠뜨린 것으로 보고 `E-SYN-007`입니다.

### 결과 돌려주기

`값을 반환한다.`는 값을 돌려주고 함수를 끝냅니다. `반환한다.`만 쓰면 `없음`을 돌려줍니다. 마지막 문장의 값을 저절로 돌려주지는 않습니다.

함수 안에서 정의한 함수는 바깥 변수를 기억합니다(클로저).

### 동사

어떤 동사든 함수 이름이 될 수 있습니다. `가르치는 법`, `돕는 법`, `팩토리얼구하는 법`처럼 정의하면 국어 활용 규칙에 따른 모든 활용형으로 부를 수 있습니다.

| 규칙 | 예 |
| --- | --- |
| 받침에 따른 어미 | 읽는다와 간다, 읽으면과 가면, 읽은과 간 |
| `ㄹ` 탈락 | 만들다: 만드는, 만든다 |
| `으` 탈락, 모음 축약 | 쓰다: 써서, 가르치다: 가르쳐서, 보다: 봐서 |
| `ㄷ`, `ㅂ`, `ㅅ`, `르` 불규칙 | 듣다: 들어서, 돕다: 도와서, 잇다: 이어서, 고르다: 골라서 |
| `우`와 `러` 불규칙 | 푸다: 퍼서, 이르다: 이르러서 |
| 본말과 준말 | 되어서와 돼서, 하여서와 해서 (둘 다 표준어) |

불규칙 활용은 철자로 가릴 수 없어서(듣다: 들어서, 닫다: 닫아서) 표준국어대사전의 불규칙 용언 목록을 따릅니다. `닫아서`는 받고 `달아서`는 받지 않습니다. 걷다, 묻다, 굽다처럼 규칙과 불규칙 동음이의어가 함께 있는 말은 두 활용을 모두 받습니다.

활용형 하나가 여러 기본형으로 읽히기도 합니다. `사는`은 사다와 살다, `걸어서`는 걷다와 걸다입니다. 어느 동사인지는 프로그램에 정의된 동사로 정합니다. 맞는 정의가 하나면 그 동사를 부르고, 안쪽 범위의 정의가 먼저입니다. 같은 범위에서 둘 이상 맞으면 `E-CALL-009`, 하나도 없으면 `E-RESOLVE-001`입니다.

정의 `사는 법`은 사다와 살다 두 기본형 모두로 불립니다. 출력할 때는 쓴 그대로 `<함수 사는 법>`으로 보입니다.

보조 용언 "-어 있다"는 맞춤법대로 띄어 써도 한 서술어입니다. `비어 있으면`은 `비어있다`, `들어 있는`은 `들어있다`의 활용입니다.

`있다`, `없다`는 내장 동사지만 같은 이름이나 `들어있다`처럼 앞에 이름을 붙여 다시 정의할 수 있습니다. `호출하다`, `반환하다`, `바꾸다`는 고정 문장에 쓰이므로 함수 이름으로 쓸 수 없습니다(`E-SYN-011`).

### 형용사와 "-는지"

참이나 거짓을 돌려주는 함수는 형용사로 정의할 수 있습니다. 헤더는 "-ㄴ지"로 끝납니다.

```ieum
`품목`이 부족한지:
    (`품목`의 수량 < `품목`의 최소수량)을 반환한다.

창고[0]이 부족하면:
    "주문하세요."를 출력한다.
(창고[0]이 부족한지)를 출력한다.
창고 중 부족한 품목마다:
    품목의 이름을 출력한다.
```

형용사는 조건(`부족하면`), 값(`(창고[0]이 부족한지)`), 반복의 관형절(`부족한 품목마다`)로 씁니다. 활용 규칙은 동사와 같고, `ㅎ` 불규칙(파랗다: 파란, 파라면)도 따릅니다.

형용사를 동사 활용(`부족한다`, `부족하는`)으로 부르거나, 동사를 형용사 활용(`읽은지`)으로 부르면 `E-FORM-003`입니다.

동사로 묻는 함수는 "-는지"로 정의합니다. `` `수`가 `약수`로 나누어떨어지는지: ``는 동사 `나누어떨어지다`를 정의하고, `(10이 5로 나누어떨어지는지)`, `3으로 나누어떨어지는 수마다`로 씁니다. `가는지`처럼 동사의 "-는지"로도 형용사의 "-ㄴ지"로도 읽히는 정의(`가다`, `가늘다`)는 두 품사의 활용을 모두 받습니다.

## 호출

| 형태 | 예 | 쓰임 |
| --- | --- | --- |
| 서술 | `3을 늘린다.` | 문장으로 호출. 결과는 버림 |
| 명사화 | `(3을 늘린 값)` | 결과를 값으로 씀. 항상 괄호로 감쌈 |
| 순차 | `열고 닫는다.` | 앞 절을 실행한 뒤 다음 절을 실행 |
| 전달 | `3을 늘려서 출력한다.` | 앞 절의 결과를 다음 절에 넘김 |
| 조건 | `3을 늘리면:` | 결과(논리값)로 조건을 검 |
| 정의 | `` `수`를 늘리는 법: `` | 함수 정의 |

전달(`-어서/-해서`)로 넘긴 결과는 사용자 함수에서는 `을/를` 매개변수가 받고, `을/를` 매개변수가 없으면 하나뿐인 매개변수가 받습니다. 받을 인자가 없으면 `E-CALL-004`입니다.

```ieum
"설정.json"을 읽어서 JSON해석한 값
```

내장 동사는 받는 인자가 동사마다 정해져 있습니다. `치환하다`는 `에서`, `시작하다`와 `끝나다`는 `이/가`, `있다`와 `없다`는 `에` 인자로 받으며, 전체 목록은 [내장 동사](stdlib.md)에 있습니다.

함수를 값으로 쓸 때는 `(늘리다)`처럼 동사 원형을 괄호로 감쌉니다. 변수에 담긴 함수는 `호출하다`로 부릅니다.

```ieum
`수`를 늘리는 법:
    (`수` + 1)을 반환한다.

동작은 (늘리다)이다.
((동작)으로 3을 호출한 값)을 출력한다.
```

## 조건

```ieum
점수가 90 이상이면:
    "우수"를 출력한다.
그렇지 않으면:
    "보통"을 출력한다.
```

| 헤더 | 뜻 |
| --- | --- |
| `A가 B 이상이면:` (`이하`, `초과`, `미만`) | 크기 비교 |
| `A가 B보다 크면:` (`작으면`, `많으면`, `적으면`, `높으면`, `낮으면`) | 크기 비교 |
| `A가 B이면:`, `A가 B와 같으면:` | 같음 |
| `A가 B가 아니면:`, `A가 B와 다르면:` | 다름 |
| `자료에 3이 있으면:`, `글이 "가"로 시작하면:` | 동사 조건형. 결과가 논리값이어야 함 |
| `(식)이면:`, `합격이면:` | 논리값 |
| `글이 "가"로 시작하지 않으면:`, `A가 B보다 크지 않으면:` | 부정 |

`많다`와 `높다`는 `크다`와, `적다`와 `낮다`는 `작다`와 같습니다. `B보다 A가 크면`처럼 어순을 바꿔도 됩니다.

부정은 국어의 긴 부정문(장형 부정)을 따라 어느 절이든 "-지 않-"으로 씁니다. 동사와 형용사의 "-지" 뒤에 `않다`를 활용합니다: `않으면`, `않고`, `않거나`, `않는`(동사), `않은`(형용사), `않는지`.

`그렇지 않으면:`은 바로 앞 조건에 붙습니다. 여러 갈래는 `그렇지 않고`로 잇습니다.

```ieum
점수가 90 이상이면:
    "우수"를 출력한다.
그렇지 않고 점수가 70 이상이면:
    "보통"을 출력한다.
그렇지 않으면:
    "노력"을 출력한다.
```

### 절 잇기

절은 "-고"(그리고)와 "-거나"(또는)로 잇습니다.

```ieum
점수가 0 미만이거나 100 초과이면:
    "범위 밖"을 출력한다.
글이 "가"로 시작하고 "다"로 끝나면:
    "가로 시작해 다로 끝남"을 출력한다.
자료에 3이 있거나 4가 있으면:
    "있음"을 출력한다.
```

뒤 절은 앞 절이 말한 것을 생략할 수 있습니다. 주어가 없는 비교(`100 초과이면`, `0이 아니면`)는 앞 절의 주어를 받고, 동사는 정의상 필요한데 쓰지 않은 인자를 앞 절에서 받습니다(`"다"로 끝나면`의 주어 `글`, `4가 있으면`의 `자료에`).

`합격이면`처럼 주어 없이 완결되는 절은 앞 절의 주어를 받지 않습니다. 리터럴만 있는 절은 앞 절의 주어와 비교합니다: `명령이 "완료"이거나 "삭제"이면`.

국어에는 "-고"와 "-거나" 사이의 우선순위가 없으므로 한 조건에 둘을 섞으면 `E-SYN-014`입니다. 섞어야 하면 한쪽을 이름으로 나눕니다.

절을 잇는 방법은 `-인 동안:`과 반복의 관형절에서도 같습니다: `차례가 0 이상이고 3 미만인 동안:`.

### 두 가지로 읽히는 헤더

`-이면`과 `-면`은 두 가지로 읽힐 수 있습니다. `분류가 정보이면:`은 `정보`와의 비교이거나 동사 `정보이다`의 조건형이고, `줄이면:`은 이름 `줄`의 논리값이거나 동사 `줄이다`의 조건형입니다. 프로그램에 정의된 쪽으로 읽고, 두 쪽이 다 맞으면 `E-RESOLVE-002`입니다. `이상`, `이하`, `초과`, `미만`은 언제나 비교입니다.

### 조건을 값으로 쓰기

괄호 안의 "-인지"나 "-는지"는 조건 전체를 값으로 만듭니다: `(수가 0보다 큰지)`, `(이름이 "가"인지)`, `(점수가 0 이상이고 100 이하인지)`.

조건에 따라 두 값 중 하나를 고르려면 `(조건이면 값, 아니면 값)`으로 씁니다: `(점수가 60 이상이면 "합격", 아니면 "불합격")`. 고른 값만 계산합니다. 조건은 `-면:` 조건문과 같은 규칙을 따르고, 여러 갈래는 괄호로 감싸 잇습니다: `(A이면 1, 아니면 (B이면 2, 아니면 3))`.

## 반복

```ieum
[1, 2, 3] 중 수마다:
    수를 출력한다.

1부터 10까지 수마다:
    수를 출력한다.

차례가 3 미만인 동안:
    차례를 1만큼 늘린다.
```

목록, 튜플, 집합, 문자열은 원소마다, 사전은 키마다 반복합니다. 이름 두 개로 반복하면 원소를 둘씩 나눠 받고, 사전은 키와 값을 받습니다: `점수표 중 이름과 점수마다:`. 둘씩 묶이지 않은 원소는 `E-ITER-002`입니다.

`A부터 B까지`는 정수 A부터 B까지 1씩 세며 B도 포함합니다. A가 B보다 크면 한 번도 돌지 않고, 내려가며 세려면 `10부터 1까지 내려가며 수마다:`로 씁니다. 정수가 아니면 `E-TYPE-001`입니다.

`동안` 헤더는 조건 헤더와 같은 비교를 `-인 동안` 형태로 씁니다: `A가 B 미만인 동안:`, `A가 B인 동안:`, `A가 B가 아닌 동안:`, `(식)인 동안:`.

`반복을 중단한다.`는 반복을 끝내고, `다음으로 진행한다.`는 다음 차례로 넘어갑니다. 반복할 때마다 원소 변수가 새로 생기므로 클로저는 그 차례의 값을 기억합니다.

### 관형절로 거르기

`중`과 `이름마다` 사이에 관형절을 넣으면 조건에 맞는 원소만 돕니다. 관형절은 `-인`(비교, 같음, 아님, 논리식), 동사의 관형형(`시작하는`, `있는`), 형용사의 관형형(`부족한`)으로 끝납니다. 범위 뒤에서는 `중`을 생략해도 됩니다: `1부터 100까지 짝수인 수마다:`.

```ieum
학생들 중 학생의 점수가 80 이상인 학생마다:
    학생의 이름을 출력한다.

이름들 중 이름이 "김"으로 시작하는 이름마다:
    이름을 출력한다.
```

관형절이 비워 둔 자리는 꾸밈받는 원소가 채웁니다("부족한 품목"은 품목이 부족한 품목입니다). 원소는 주어 없는 비교(`80 이상인 점수마다`)의 주어가 되거나, 정의된 함수가 비워 둔 필수 인자 하나를 채웁니다(`"김"으로 시작하는 이름마다`).

관형절의 주어가 정의되지 않은 이름이면 꾸밈받는 원소의 속성입니다("꼬리가 긴 고양이"의 꼬리는 고양이의 꼬리입니다). `학생들 중 점수가 80 이상인 학생마다`의 `점수`는 `학생의 점수`입니다. 같은 이름이 정의되어 있으면 그 이름을 씁니다.

### 모음을 값으로 다루기

```ieum
우수자들은 (학생들 중 학생의 점수가 90 이상인 학생들)이다.
정리된것은 (이름들 각각을 다듬은 값)이다.
이름들 각각을 출력한다.
```

`(모음 중 [관형절] 원소들)`은 관형절이 맞는 원소만 모은 새 목록입니다. 원소 이름에 `들`을 붙이고, 범위 뒤에서는 반복처럼 `중`을 생략해도 됩니다: `(1부터 100까지 짝수인 수들)`.

인자에 `각각`을 붙이면 원소마다 호출합니다. 값으로 쓰면 결과의 목록이 되고(`(이름들 각각을 다듬은 값)`), 문장으로 쓰면 원소마다 실행합니다(`이름들 각각을 출력한다.`). `각각`은 한 문장에 한 번만 씁니다(`E-SYN-015`).

조건에서 `모음 중 [관형절] 원소가 있으면`은 하나라도 맞는지, `원소가 없으면`은 하나도 맞지 않는지 묻습니다. 이어진 절은 `모음 중`을 생략할 수 있습니다: `점수들 중 90 이상인 점수가 있고 40 미만인 점수가 없으면:`.

### 함께 실행하기

기다리는 일(네트워크, `기다리다`)이 여럿이면 `함께`로 동시에 기다립니다.

```ieum
함께:
    날씨는 ('https://example.com/날씨'에서 내려받은 값)이다.
    소식은 ('https://example.com/소식'에서 내려받은 값)이다.
"{날씨} {소식}"을 출력한다.

본문들은 (주소들 각각에서 함께 내려받은 값)이다.
```

`함께:` 안의 문장은 저마다 하나의 흐름으로 실행되고, 모든 흐름이 끝나면 다음 문장으로 갑니다. 한 흐름이 기다리는 동안 다른 흐름이 실행되지만 계산은 한 번에 하나씩 합니다.

`함께:` 안에서 정의한 이름은 바깥 블록의 이름입니다. 흐름끼리는 실행 순서가 정해져 있지 않아서 한 흐름이 다른 흐름의 이름을 쓰면 `E-INIT-001`입니다. 흐름 안에서는 반환하거나 바깥 반복을 멈출 수 없습니다(`E-SYN-017`).

`각각`과 함께 쓰면 원소마다 흐름을 만듭니다. `(주소들 각각에서 함께 내려받은 값)`은 결과를 원소 순서대로 모은 목록이고, `주소들 각각을 함께 처리한다.`는 모든 원소를 동시에 처리합니다. 문장 안의 `함께`는 `각각`과 같이 씁니다(`E-SYN-016`).

한 흐름이 잡지 않은 오류는 `함께` 전체의 오류이고, 나머지 흐름은 취소됩니다. 취소된 흐름은 오류 처리 블록에 잡히지 않고 정리 블록(`마지막으로:`)만 실행한 뒤 끝납니다. 모든 흐름이 끝나면 그 오류가 `함께`에서 발생하고, 바깥의 `시도한다`로 잡을 수 있습니다.

### 병렬로 계산하기

`병렬로`는 계산을 여러 코어에 나눠 실행합니다. 같은 계산을 원소마다 나눌 때는 `각각`과 같이 쓰고, 서로 다른 계산을 동시에 할 때는 `병렬로:` 블록을 씁니다.

```ieum
`끝`에서 소수를 세는 법:
    개수는 0이다.
    2부터 `끝`까지 수마다:
        수가 소수이면:
            개수를 1만큼 늘린다.
    개수를 반환한다.

개수들은 ([100000, 200000, 300000] 각각에서 소수를 병렬로 센 값)이다.
사진들 각각을 병렬로 줄인다.

병렬로:
    작은쪽은 (100000에서 소수를 센 값)이다.
    큰쪽은 (300000에서 소수를 센 값)이다.
"{작은쪽} {큰쪽}"을 출력한다.
```

`각각`과 쓴 식은 결과를 원소 순서대로 모은 목록이고, 문장은 원소마다 실행합니다. `함께`와 한 문장에 같이 쓸 수 없습니다(`E-SYN-016`).

`병렬로:` 안의 문장은 저마다 따로 계산하고, 모든 문장이 끝나면 다음 문장으로 갑니다. 문장이 정의한 이름은 그때 바깥 블록의 이름이 되며 보통 값처럼 바꿀 수 있습니다. 문장끼리 서로의 이름을 쓰면 `E-INIT-001`이고, 블록 안에서는 반환하거나 바깥 반복을 멈출 수 없습니다(`E-SYN-017`).

계산은 원소와 바깥 변수의 복사본으로 하므로, 바깥 변수나 바깥의 목록, 사전, 원소를 고치면 `E-PAR-001`입니다. 결과도 복사본입니다.

출력과 오류는 차례로 실행했을 때와 같습니다. 출력은 원소나 문장 순서대로 나오고, 어떤 원소에서 오류가 나면 그 뒤의 원소는 새로 시작하지 않으며 가장 앞선 원소의 오류가 발생합니다.

`병렬로` 안에서는 `묻다`를 쓸 수 없습니다.

## 오류 처리

```ieum
시도한다:
    (10 // 0)을 출력한다.
오류를 문제로 받으면:
    문제의 메시지를 출력한다.
마지막으로:
    "정리 완료"를 출력한다.
```

`시도한다:` 뒤에는 오류 처리, 정리, 또는 둘 다를 이 순서로 둡니다. 정리 블록은 정상 완료, 반환, 반복 제어, 일반 실행 오류 때 한 번 실행됩니다. 정리 블록이 새로 반환하거나 오류를 내면 그 결과가 앞의 결과를 대신합니다.

`오류 "설명"을 발생시킨다.`는 `E-USER-001` 오류를 만듭니다. `오류를 다시 발생시킨다.`는 처리 중인 오류를 다시 던지고, 받은 오류 값은 `오류 문제를 발생시킨다.`로 다시 던질 수 있습니다. 처리 중에 생긴 새 오류는 처리하던 오류를 `원인`으로 기록합니다.

구문 오류나 이름 오류 같은 정적 오류, 실행 한도 초과, 내부 오류는 잡을 수 없습니다.

### 실행 끝내기

`실행을 끝낸다.`는 프로그램을 그 자리에서 끝냅니다. `실행을 2로 끝낸다.`처럼 종료 코드(0~255)를 줄 수 있습니다. 오류 처리 블록은 이것을 잡지 않지만 정리 블록(`마지막으로:`)은 실행됩니다.

종료 코드가 0이 아니면 명령줄 실행은 메시지 없이 그 코드로 끝납니다. Rust API에서는 `E-EXIT-001` 오류이고 `exit_code`에 코드가 담깁니다. 대화형 실행에서는 세션을 끝냅니다.

## 자료형

```ieum
사람은 이름과 나이(기본 0)를 가진다.

철수는 (이름이 "김철수"이고 나이가 25인 사람)이다.
철수의 나이를 26으로 바꾼다.
철수를 출력한다.
```

출력은 `사람(이름: "김철수", 나이: 26)`입니다.

자료형은 `X는 A와 B를 가진다.`로 정의합니다. 필드는 와/과로 잇고 마지막 필드에 을/를을 붙입니다. 자료형 이름에는 다른 값을 넣을 수 없습니다.

기본값은 함수 인자처럼 `(기본 식)`으로 쓰고 정의할 때 한 번 계산합니다. `친구들(기본 [])` 같은 가변 기본값은 그 기본값을 쓴 모든 값이 공유합니다.

값은 필드와 값을 `-이고`로 잇고 끝에 자료형 이름을 붙여 만들며, 필드 순서는 자유입니다. 기본값이 없는 필드를 빼면 `E-RECORD-001`, 없는 필드를 쓰면 `E-RECORD-002`, 같은 필드를 두 번 쓰면 `E-RECORD-003`입니다. 자료형 정의(가져온 것 포함)를 이름으로 바로 쓰는 값은 이를 실행 전에 검사합니다.

필드는 `의`로 읽고 `바꾼다`로 바꿉니다. 사전과 달리 필드 이름이 `길이`여도 필드를 읽습니다.

`==`는 같은 자료형의 필드끼리 비교합니다. 정의 문장을 실행할 때마다 새 자료형이 생깁니다. `JSON변환하다`는 필드 이름을 키로 하는 객체를 만듭니다.

메서드는 없습니다. 자료형을 다루는 일은 `` `사람`에게 인사하는 법: ``처럼 함수로 정의합니다.

## 여러 파일과 테스트

```ieum
"계산"에서 합산하다와 기준을 가져온다.

(3을 4와 합산한 값)을 출력한다.
```

이 문장은 같은 폴더의 `계산.이음`에서 이름을 골라 가져옵니다. 경로는 가져오는 파일을 기준으로 하고 확장자는 쓰지 않습니다: `"도구/정렬"`, `"../공통/계산"`. 가져오기는 파일 맨 앞에 모아 씁니다.

파일의 최상위 이름은 모두 가져갈 수 있습니다. 가져온 이름은 바꿀 수 없고, 변수를 가져오면 가져올 때의 값이 담깁니다.

같은 파일은 한 번만 실행하며, 순환 가져오기는 오류입니다. 모든 파일의 검사가 끝난 뒤에 실행을 시작합니다.

테스트는 이름이 `test_`로 시작하는 파일이고, 오류 없이 끝나면 통과입니다.

```ieum
"계산"에서 합산하다를 가져온다.

((2를 3과 합산한 값) == 5)를 확인한다.
```

`ieum test 폴더`는 폴더와 하위 폴더의 `test_*.이음`을 찾아 각각 새 상태에서 실행합니다.

## 실행과 도구

| 명령 | 하는 일 |
| --- | --- |
| `ieum 파일.이음 [인자...]`, `ieum run 파일.이음 [인자...]` | 검사한 뒤 실행. 정적 오류는 첫 번째만 보고 |
| `ieum check 파일.이음` | 실행하지 않고 구문, 이름, 호출 검사. 오류를 64개까지 모두 보고 |
| `ieum fmt [--check] 파일.이음` | 정리한 코드 출력. `--check`는 출력 없이 정리가 필요한지만 검사 |
| `ieum test [폴더]` | 폴더(기본: 현재 폴더)와 하위 폴더의 `test_*.이음` 실행 |
| `ieum repl` | 대화형 실행 |
| `ieum lsp` | 편집기용 언어 서버(LSP) |
| `ieum dis 파일.이음` | 컴파일된 바이트코드를 함수마다 원문 줄 번호와 함께 출력 |

실행할 때 파일 뒤에 준 인자는 `실행인자`로 읽습니다. 파일 대신 `-`를 쓰면 표준 입력을 읽습니다. 프로그램 안의 파일 경로는 실행을 시작한 폴더를 기준으로 합니다([파일과 경로](stdlib.md#파일과-경로)).

`ieum fmt`는 공백, 기호 간격, 줄바꿈만 고치고 주석, 철자, 순서는 그대로 둡니다. `ieum dis`의 출력 형식은 사람이 읽기 위한 것이라 바뀔 수 있습니다.

| 종료 코드 | 뜻 |
| --- | --- |
| 0 | 성공 |
| 1 | 언어 오류, 실패한 테스트, `fmt --check`에서 정리가 필요함 |
| 2 | 잘못된 명령, 읽을 수 없는 입력 파일 |

### 오류 보고

오류는 `파일:줄:열: 코드: 메시지` 형식으로 보고하고, 그 아래에 그 줄과 위치를 보입니다. 고칠 방법을 짐작할 수 있으면 `도움말`을 붙입니다.

```text
계산.이음:2:1: E-RESOLVE-001: '합게' 이름을 찾을 수 없습니다.
  2 | 합게를 1만큼 늘린다.
    | ^^^^
  도움말: 혹시 '합계'를 쓰려고 했나요?
```

실행 오류에는 내장 동사를 포함한 호출 경로를 가장 안쪽부터 최대 64개까지 붙입니다. 정적 오류가 있으면 아무것도 실행하지 않습니다.

### 대화형 실행

표현식만 입력하면 값을 보여 주고, 블록은 빈 줄로 끝냅니다. 다른 입력에서 같은 이름을 다시 정의할 수 있지만 상수는 다시 정의할 수 없습니다. 명령은 `:도움말`, `:취소`, `:초기화`, `:끝`입니다.

## 실행 한도

한도를 넘으면 `E-LIMIT-001`이고, 메시지에 어느 한도인지 나옵니다.

### 바꿀 수 있는 한도

Rust API의 `Limits`로 바꿉니다. 명령줄 실행, `ieum test`, 대화형 실행에는 명령어 수, 힙 객체, 힙 바이트 한도가 없어 메모리가 허락하는 만큼 씁니다.

| 항목 | 기본값 |
| --- | --- |
| 실행한 바이트코드 명령어 | 1,000,000개 |
| 함수 호출 깊이 | 1,024 |
| 힙 객체 | 1,000,000개 |
| 힙 바이트 | 256 MiB |

### 고정 한도

| 항목 | 한도 |
| --- | --- |
| 소스 파일 하나 | 1 MiB, 토큰 262,144개 |
| 중첩 | 괄호 32단계, 블록 32단계 |
| 식 하나의 깊이 | 64 |
| 정수 | 1,048,576비트 |
| 문자열(읽은 파일, 출력할 값 포함) | 16 MiB |
| 목록, 튜플, 집합, 사전 하나, JSON이나 CSV 문서 하나 | 원소 16,777,216개 |
| JSON 중첩 | 64단계 |
| 여러 파일 프로그램 | 파일 128개, 합계 8 MiB |
