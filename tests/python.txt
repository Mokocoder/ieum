=== 모듈, 속성, 호출, 연산
수학은 ("math"를 파이썬에서 가져온 값)이다.
(((수학의 sqrt)로 [16]을 호출한 값), 수학의 pi > 3)을 출력한다.
(((수학의 factorial)로 [25]를 호출한 값), ((수학의 isqrt)로 [10 ** 30]을 호출한 값))을 출력한다.
분수는 ("fractions"를 파이썬에서 가져온 값)이다.
삼분의일은 ((분수의 Fraction)으로 [1, 3]을 호출한 값)이다.
(삼분의일 + 1, -삼분의일, 삼분의일 * 3 == 1, 삼분의일 < 1)을 출력한다.
삼분의일을 출력한다.
((삼분의일을 문자열변환한 값), (삼분의일을 실수변환한 값), "값: " + 삼분의일)을 출력한다.
---
(4.0, 참)
(15511210043330985984000000, 1000000000000000)
(Fraction(4, 3), Fraction(-1, 3), 참, 참)
1/3
("1/3", 0.3333333333333333, "값: 1/3")
=== 이름 붙은 인자, 인덱스, 바꾸기, 반복
내장은 ("builtins"를 파이썬에서 가져온 값)이다.
정렬은 ((내장의 sorted)로 [[3, 1, 2]]를 {"reverse": 참}과 호출한 값)이다.
(정렬[0], 정렬[1:], 정렬의 길이)를 출력한다.
정렬[0]을 10으로 바꾼다.
정렬을 출력한다.
공간은 (("types"를 파이썬에서 가져온 값)의 SimpleNamespace)이다.
객체는 ((공간)으로 {"가": 1}과 호출한 값)이다.
객체의 가를 2만큼 늘린다.
객체를 출력한다.
세기는 ((("collections"를 파이썬에서 가져온 값)의 Counter)로 ["가나가"]를 호출한 값)이다.
세기 중 글자마다:
    (글자, 세기[글자])를 출력한다.
(세기를 목록변환한 값)을 출력한다.
시도한다:
    ((내장의 int)로 ["가"]를 호출한 값)을 출력한다.
오류를 문제로 받으면:
    (문제의 코드, 문제의 메시지)를 출력한다.
---
(3, [2, 1], 3)
[10, 2, 1]
namespace(가=3)
("가", 2)
("나", 1)
["가", "나"]
("E-PY-002", "ValueError: invalid literal for int() with base 10: '가'")
